# Little-English-Hero
Little English Hero là ứng dụng di động giáo dục hỗ trợ trẻ em từ 3 đến 8 tuổi học các từ vựng tiếng Anh cơ bản. Ứng dụng phương pháp Trò chơi hóa nhằm biến các bài học ngôn ngữ thành cuộc vui chơi ngắn, giúp trẻ tiếp cận kiến thức mới một cách dễ dàng nhất.
